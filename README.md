### 🔴 01 — JINETE

#### Ride Together. Save Together.

Jinete is a ride-sharing application designed to make everyday commuting simpler and more convenient. It focuses on connecting riders with an intuitive ride-booking experience.

**What it offers**

- 🚘 Ride requests with pickup and drop-off locations
- 📍 Interactive maps and location selection
- 🔄 Ride status tracking
- 📱 A streamlined mobile experience for everyday commuting

**Technology**

`React Native` `Expo SDK 54` `Firebase`
